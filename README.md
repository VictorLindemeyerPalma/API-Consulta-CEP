# API-Consulta-CEP
(ING) Modular Python API for address data validation, retrieval, and formatting via ZIP code. Developed following PEP 8 standards, featuring robust exception handling (Requests) and a component-oriented architecture (main orchestrator, validation, external integration with the ViaCEP API, and presentation layer).

(PT-BR) API modular em Python para validação, consumo e formatação de dados de endereços via CEP. Desenvolvida seguindo padrões PEP 8, tratamento robusto de exceções (Requests) e arquitetura orientada a componentes (orquestrador principal, validação, consulta externa à API ViaCEP e camada de exibição).
